# Homer Tools

## Introduction

Homer Tools is a family of free, open source Windows apps by a blind
developer, for people who work by keyboard and screen reader. The Homer brand
has carried this author's software for many years.

Each app is a 64-bit Windows program, written in C# or Python, MIT-licensed,
with source code on GitHub. Most run as a dialog or from the command line,
with the same options either way, named consistently across apps, so hand
work can be scripted. Each installs from one simple installer and speaks
through JAWS and NVDA directly.

Each ships the same documents, in HTML and Markdown: **ReadMe** for a quick
start, **Announce** for what is new, its **own guide** for full reference,
**Developer** for how it is built, **History** for changes, and **Hotkeys**
for every keystroke.

## The Apps

Fuller descriptions are in [Homer Resources][resources].

- [2htm][2htm] — converts Word, Excel, and PowerPoint files to clean HTML.
  [Installer][2htm-setup].
- [bookFido][bookfido] — catalogs your books across Audible, Bookshare,
  Goodreads, Kindle, and NLS BARD. [Installer][bookfido-setup].
- [DbDo][dbdo] — manages SQLite, Access, Excel, and other databases from the
  keyboard. [Installer][dbdo-setup].
- [EdSharp][edsharp] — edits text and program code, speaking the result of
  each command. [Installer][edsharp-setup].
- [extCheck][extcheck] — checks Word, Excel, PowerPoint, and Markdown files
  for accessibility. [Installer][extcheck-setup].
- [FileDir][filedir] — manages files and folders by typed command.
  [Installer][filedir-setup].
- [HomerScribe][homerscribe] — describes video and transcribes audio, using
  AI models on your own machine. [Installer][homerscribe-setup].
- [HomerView][homerview] — an NVDA add-on that asks Microsoft Edge directly
  what is on a page. [Installer][homerview-setup].
- [urlCheck][urlcheck] — tests web pages and drafts an Accessibility
  Conformance Report. [Installer][urlcheck-setup].
- [urlFido][urlfido] — downloads every file of a chosen kind from a web page.
  [Installer][urlfido-setup].
